# Landing Page với Bootstrap và Hình Ảnh

Hero có ảnh lớn, hàng giới thiệu ảnh + mô tả, 3 tính năng có icon, tiêu đề, mô tả và CTA btn-lg. Bootstrap 5 hero tự xây dựng, ảnh cục bộ img-fluid.

## Chạy
Mở index.html. Cần Internet để tải Bootstrap 5.3.0 CSS và bundle từ jsDelivr, đúng phiên bản trong đề thực hành.
